# 浏览器产品体验与稳定性收尾

> 执行：并行实现相互独立的界面、数据和原生部分，主会话集成并在 Android WebView 验收。

## 目标与设计

以网页内容为主，默认底部单行工具栏。切换地址栏到顶部时移动整条工具栏，不重复堆叠导航。搜索按需展开，菜单只容纳动作；历史、书签、标签、脚本、设置采用统一子页。所有页面接入现有主题。保留当前浏览器、媒体嗅探、用户脚本和本地数据能力。

## 约束

- 在 feat/browser-unified-ux-20261017 现有隔离工作区继续；不改变 beta。
- 不新增生产依赖，不替换 System WebView，不改变应用版本。
- 既有浏览历史、书签、快捷方式、搜索和地址位置存储键兼容。
- 界面不出现开发说明、营销口号；空状态和失败状态提供明确操作。
- 使用 emulator-5554 调试包，安装前备份数据，覆盖安装，不清数据。

## 证据与审查重点

- 既存 /tmp/nn-crash.log 记录 BrowserHostPlugin.onProgressChanged 的空 TextView 导致主线程 NPE；当前提交已有空值保护，需要验证。
- 搜索打开未隐藏原生 WebView；返回键未覆盖全部弹层。
- 首页尚未创建原生会话时，新建标签和下载动作无效。
- 脚本修改仅保存前端，现有原生脚本快照不更新。
- 本地数据形状未校验、保存失败未处理。
- renderer 退出后旧恢复直接关闭最后一个标签，不能保留可恢复状态。

## 工作项

- [x] 原生会话：安全处理进度、渲染进程退出、错误标签重建、迟到回调；同步脚本快照。
- [x] 前端会话：独立生命周期 hook、覆盖层可见性、异步操作与关闭一致性、错误提示和网页真实标题。
- [x] 工具栏、主页、搜索：单条工具栏，常用动作可达，搜索不被原生网页覆盖，输入失败保留。
- [x] 历史、书签、标签与设置：统一子页、过滤、空状态、保存反馈、完整返回行为。
- [x] 脚本和数据：安装/更新/启停/删除状态完整；非法持久化数据可恢复，保存失败保留输入。
- [x] 验证：针对性行为测试、类型与lint、原生测试、调试APK构建安装；实际操作和明暗主题截图。

## 验收

1. 单层工具栏，上下位置切换后网页边界立即正确。
2. 搜索、菜单、子页、媒体播放及确认层打开/返回时，原生网页可见性与触摸一致。
3. 新建/关闭/切换标签、历史与书签、快捷方式管理、脚本更改和页面刷新均有可观察结果。
4. 出错保留输入和网址；重试不影响其他标签。对异步和曾异常路径连续验证三轮。
5. 所有检查结果写入同目录验收记录，截图位于 evidence/browser-product-20261017。
