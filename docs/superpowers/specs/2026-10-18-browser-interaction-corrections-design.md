# 浏览器交互修正设计（2026-10-18）

本轮基于 `e5188c22510cfb5854b9ba78f0a7cca81d6459b0`，按用户本次六项反馈修正上一轮产品定义。

## 产品目标与验收

1. 隐私模式是默认关闭、可持久保存的浏览记录开关。同一进程、同一标签立即生效；开启后不保存新的搜索、浏览、最近访问记录，不恢复私密页面。已存历史不自动删除；用户明确保存的书签、快捷方式、设置和下载仍可使用。关闭后不把私密期间记录补写回来。
2. 已打开页面安装、编辑、启停或删除脚本后，点击刷新即可使用最新脚本。“匹配此网页”按最新启用配置与当前网址实时计算；“此页已运行”来自本次文档实际开始执行的脚本数，不能把已安装总数或待刷新配置当成本页生效数。导航、错误和脚本准备生命周期必须隔离。
3. 看图模式保持独立入口和原网站图片行为；缩略图请求不得挤掉当前主图。快速翻页/切图、请求失败、重新扫描、返回重进都有明确可恢复状态。主图继续使用现有缩放、上一张/下一张、预览条和分享。
4. 搜索服务项仅切换选择，保留输入、焦点和搜索界面。提交按钮或键盘确认才搜索；空输入不得因切换服务而跳走。
5. 桌面网页同时改变请求身份和布局视口。当前 `useWideViewPort`/overview 仍尊重网站手机 viewport，需要补足；关闭后恢复原手机/自定义UA，持久化该选择。
6. 浏览设置支持系统默认、Android、iOS、自定义标识以及独立桌面网页开关；现有文字缩放、图片、JavaScript、第三方Cookie、媒体播放、外部应用、搜索/地址栏位置/数据清理按清晰分组整理。

## 边界

- 无新增生产依赖；保留 React/Capacitor 本地优先架构和 Android minSdk 24。
- 浏览器设置沿用 `newsnook:browser:preferences:v1`，新增字段有默认和迁移；Native privacy 位仅作启动与日志镜像。
- 不承诺UA选择能改变WebView引擎；不为兼容性添加网站绕过或不安全TLS规则。
- 旧 `:browser_private` 架构移除，仅对其专有目录保留严格范围的升级清理。
- 中文界面，复用主题、字体、字号、圆角和至少44px触控目标；避免实现说明堆入产品。
- 设备验证使用已有独立 browseraudit 包，不读写或清理用户 debug 包。

## 已观察根因

- 图片：连续分页填满32项缩略队列后，主图被拒绝且错误未进入视图状态；队列排空后仍没有主图请求。
- 脚本：当前WebView在运行时替换脚本绑定后，reload路径缺少新页面桥对象；同URL的显式loadUrl能注入并运行更新脚本。修复只对脚本绑定变更后的刷新走新文档加载，普通刷新保持既有行为。
- 桌面：原实现只有UA替换和wide/overview，网站的device-width viewport仍决定手机宽度；请求的Client Hints也需要与桌面UA同步，避免继续声明Android/mobile。最终策略由BrowserPageProfile统一设置UA、Client Hints和可恢复的980px布局视口，覆盖网站动态修改viewport的情况。
